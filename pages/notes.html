EVENT STREAMING

Kafka API compatibility

Redpanda implements the Kafka protocol, so many Kafka clients and developer workflows can be reused. Compatibility does not mean every operational detail or ecosystem feature is identical.

BACKEND SECURITY

Authentication is not authorization

Authentication establishes who a caller is. Authorization determines what that caller may do. A valid token alone should not grant access to every resource.

DATABASES

Persistence boundaries matter

Keep persistence concerns behind clear repository or data-access boundaries. This makes transaction handling, schema evolution and testing easier to reason about.

CONTAINERS

A container image is not a deployment strategy

Building an image is one step. Configuration, secrets, networking, health checks, logs, persistent data and rollback are part of operating the application.

LEARNING IN PUBLIC

Document the trade-off, not just the tool

A useful engineering note explains why a tool or pattern was selected, which alternatives were considered and what limitations remain.

These are concise learning notes, not claims of completed production implementations.
