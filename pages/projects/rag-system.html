Intelligent RAG System

A document-based assistant that makes information in PDF files easier to search and explore using retrieval-augmented generation.

The problem

A language model alone may not know the contents of a user's private documents. The application needs a way to ingest source material, retrieve relevant passages and ground responses in that material.

What I built

The Streamlit application accepts PDF documents, processes their content, stores searchable representations and uses retrieval to provide context to a Gemini-powered response. MongoDB Atlas Vector Search supports semantic retrieval.

My contribution

Built the RAG application and worked with document ingestion, vector search and model integration. The project uses the `sample_mflix.ragpdf` database/collection context in Atlas and was containerised for deployment.

Technology

Python · Streamlit · LangChain · Google Gemini · MongoDB Atlas Vector Search · Docker

What I learned

RAG quality depends on the full retrieval pipeline: parsing, chunking, embedding, indexing, retrieval and prompt construction. A fluent answer is not necessarily a grounded answer; source relevance and evaluation matter.
