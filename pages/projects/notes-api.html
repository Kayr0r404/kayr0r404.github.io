Notes API Platform

A notes application combining a Django REST backend and React frontend, with authentication and controlled sharing.

The problem

Users need to create and manage notes while controlling whether each note remains private or can be shared publicly. Access rules must be enforced by the backend, not only hidden in the interface.

What I built

The application provides authentication, CRUD operations and public/private sharing with permission-aware access. The React client consumes the Django REST API and uses JWT-based authentication.
