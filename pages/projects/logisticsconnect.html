LogisticsConnect

A Java multi-service project scaffold for parcel hub ingestion, delay-stage tracking, transit estimates and asynchronous status notifications.

Problem and design goal

Parcel transit information spans hub data, delay conditions and estimated arrival calculations. The repository explores separating these responsibilities into independently runnable services and replacing selected synchronous calls with message-based communication.

Architecture defined by the repository

hubs-global.csv
↓
Ingestion service · clean and expose hub data
↓ REST
Hub service · place / sorting-centre data
↘ REST
Transit service · ETA calculation
↑ status events
Delay-stage service · ActiveMQ topic producer
↓ topic subscription
Alert bot · notification consumer (stretch goal)

The README describes a progression: CSV ingestion, synchronous REST integration between services, decoupling delay updates through the package-status-topic, then an alerting consumer. ActiveMQ Classic is provisioned through the shared Docker Compose file.

Implementation status: the repository README explicitly describes the project as a scaffold with build files, Javalin bootstrap code and TODOs; business logic is not yet implemented. The diagram therefore describes the intended service contracts, not a completed end-to-end production workflow.

Technology and service boundaries

  • Runtime: Java 17 and Maven.
  • HTTP services: Javalin 5.6.3 with Jackson for JSON.
  • Messaging: ActiveMQ Classic 5.18.3 using the JMS client.
  • Services: ingestion, hub, delay-stage, transit and alert-bot modules.
  • Local broker: Docker Compose exposing OpenWire and the broker console.

Architecture considerations

The service split creates clear domain responsibilities, but asynchronous messaging introduces delivery semantics that still need implementation: durable subscriptions, retries, duplicate handling, event identifiers, ordering, dead-letter handling and observability. These are design considerations for the next implementation stages, not claims that they are already complete.
