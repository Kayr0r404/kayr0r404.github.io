PROJECT CASE STUDY · EVENT-DRIVEN APPLICATION

LogisticsConnect

A parcel-tracking application exploring asynchronous status updates and real-time communication.

The problem

A parcel's status changes over time. Consumers of that information should be able to react to updates without tightly coupling every component to the tracking service.

What I built

The project uses a Javalin application and ActiveMQ topic-based messaging for package status events, with a hub endpoint for real-time client updates.

Technology

Java · Javalin · ActiveMQ · messaging topics · real-time hubs

What I learned

Messaging allows producers and consumers to evolve more independently, but introduces operational concerns: delivery, retries, duplicate messages, ordering and consumer failure handling.
