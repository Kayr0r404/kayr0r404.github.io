PROJECT CASE STUDY · COMMUNITY PLATFORM

Plus27

An area-first digital platform designed to bring local South African communities, conversations and services into one place.

The problem

Local communities often rely on fragmented channels to discover events, find services, share information and connect with neighbours. The product concept brings those activities into a location-aware experience.

What I built

Plus27 is a community platform spanning conversations, events, groups, a local marketplace, vendor profiles, odd jobs and rental listings. The application uses a modern web frontend with backend services and data stores supporting distinct product capabilities.

My contribution

Worked on the application as a full-stack project, with particular attention to backend architecture and service design. The authentication work uses FastAPI, JWT access/refresh tokens and a data layer that has evolved through SQLModel/PostgreSQL and MongoDB/Beanie exploration.

Technology

Next.js · React · TypeScript · Tailwind CSS · FastAPI · Python · PostgreSQL · MongoDB · Docker

What I learned

A platform with multiple product areas benefits from clear domain boundaries, consistent identity and authorization, and careful data modelling. A working frontend needs reliable API contracts and environment configuration as much as polished UI.
