LEARNING SERIES · IN PROGRESS

Backend services across languages

Explore a service architecture with a Python authentication service and Java resource services, focusing on clear contracts and secure trust boundaries.

This is a learning roadmap and working set of notes. Sections will be expanded with tested code, diagrams and implementation examples as the work progresses.

PART 1

Define service responsibilities

Separate identity and token issuance from resource ownership and business operations. Decide which service owns each piece of data.

Architecture · service boundaries

PART 2

Design the token contract

Define issuer, audience, subject, expiry, scopes/roles and signing algorithm. Plan key distribution and rotation rather than sharing secrets casually.

Security · JWT

PART 3

Validate tokens in Java

Implement signature and claim validation, expiry handling, issuer/audience checks and predictable error responses in resource services.

Hands-on · Spring Boot

PART 4

Authorization at resource boundaries

Check ownership, roles, scopes and resource-level permissions. Avoid treating a valid identity token as blanket access.

Security · authorization

PART 5

Handle failure and revocation

Consider key rotation, token expiry, identity-service outages, revocation requirements and safe caching of public keys.

Reliability · operations

PART 6

Test the integration

Create contract tests, invalid-token cases, expired-token cases and end-to-end tests across the Python and Java services.

Testing · integration
