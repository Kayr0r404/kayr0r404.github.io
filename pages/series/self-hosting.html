LEARNING SERIES · IN PROGRESS

From application to self-hosted deployment

A practical learning journey from an old laptop to a small, secure home application server, with a path to stronger hardware later.

This is a learning roadmap and working set of notes. Sections will be expanded with tested code, diagrams and implementation examples as the work progresses.

PART 1

Understand the machine and operating system

Inventory hardware, install Linux, configure users, SSH, updates, firewall rules, storage and basic system monitoring.

Linux · administration

PART 2

Containerise applications

Build reproducible Docker images, configure environment variables and secrets, use persistent volumes and define health checks.

Docker · packaging

PART 3

Networking and access

Understand LAN addressing, DNS, ports, reverse proxies, TLS certificates, NAT and the risks of exposing services to the internet.

Networking · security

PART 4

Deploy and update services

Use Compose for repeatable deployments, separate development and production configuration, manage migrations and plan rollback.

Deployment · operations

PART 5

Observability and backups

Collect logs, monitor resource usage, check service health, back up databases and test restoration procedures.

Reliability · maintenance

PART 6

Harden the platform

Apply least privilege, keep services updated, restrict management access, protect secrets and document incident recovery.

Security · operations
